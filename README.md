# Supermarket Sales Analysis

## Project Overview
This project focuses on exploring supermarket sales data and presenting business insights through data analysis and visualization.

## Objectives
- Explore supermarket sales data.
- Identify sales patterns and trends.
- Present data insights through visualization.

## Tools & Technologies
- Orange Data Mining
- Microsoft Excel
- Google Sheets
- Google Looker Studio

## Project Files
- `analisis-prediktif-supermarket.ows` — Workflow for data analysis in Orange Data Mining.
- `synthetic_store_indonesia.xlsx` — Supermarket sales dataset.
- `informasi_penjualan_super_market_indonesia.pdf` — Supporting project documentation.

## Dataset & Dashboard
- [View Dataset on Google Sheets](https://docs.google.com/spreadsheets/d/1EHcRWMZ-Vc3OhergwBnEfpHbmKL93hdyFfipy3kR2sU/edit?usp=sharing)

## How to Use
1. Install Orange Data Mining.
2. Download the workflow and dataset.
3. Open the `.ows` file in Orange Data Mining.
4. Ensure the dataset path is correctly configured.
